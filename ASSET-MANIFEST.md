# Luxy — manifiesto de assets

Última actualización: 2026-08-04

No se han añadido assets visuales en el checkpoint documental actual.

Cuando se añada uno, registrar:

| Campo            | Contenido                                         |
| ---------------- | ------------------------------------------------- |
| Nombre           | archivo y variante                                |
| Propósito        | problema visual o funcional que resuelve          |
| Pantalla         | ruta/componente consumidor                        |
| Formato y tamaño | dimensiones, peso y transparencia                 |
| Procedencia      | generado, diseñado o tercero con licencia         |
| Prompt           | sólo si fue generado y no contiene datos privados |
| Variantes        | oscuro, claro, móvil, estados                     |
| Estado           | propuesto, aprobado, integrado o retirado         |

No añadir imágenes de stock irrelevantes ni recursos con licencia dudosa.
